# Итерация устойчивости 7: ложная опора и подгонка фиксированных пар

2026-10-03, продолжение [итерации 6](robustness-iteration-6.md).
Исследуется только development `wm_r_143159342`, без новых фотографий.

**В исходных 11 парах footprint подтверждена ложная опора на пальмовом листе.**
Её удаление из первого fit уменьшает ошибку Albireo 28.54→16.65 px, но
увеличивает ошибку Shaula 10.82→21.64 px. Начальные камеры control/footprint
на одинаковых парах сходятся практически к одному решению: различие задаёт
состав пар. При этом удаление ложной опоры не обеспечивает улучшения всего поля.
Изменений производственного алгоритма и автоматического улучшения здесь нет.

## Визуальная проверка восьми неподтверждённых пар

Просмотрены все 11 исходных пар выбранного footprint/default-кандидата:
общий кадр и фрагменты 150×150 исходных пикселей, увеличенные для просмотра.
Локальный контраст применяется только к превью. Численные центроиды измеряются
по неизменным исходным пикселям. Три опоры уже встречались в разметке итерации 5;
остальные восемь проверены впервые. Решения по всем парам сохранены **до**
расчёта leave-one-out и новых fit.

Итого: девять звёздных ядер с условными каталожными идентичностями,

камерами. Независимым абсолютным ground truth эта разметка не становится.
Внешний WCS этого кадра по-прежнему unresolved.

Для пары 8 соседний HYG 83247 имеет 6.06 mag, основной HYG 83221 — 5.91 mag,
угловое расстояние около 0.0848°. В таком масштабе две звезды могут влиять
на одно измеренное ядро. Пара отдельно помечена `blend`; её не объявляем
ни заведомо правильной одиночной звездой, ни подтверждённым ложным источником.

Пара 9 находится в `(2941.24, 1193.01)` исходного кадра. Вокруг измеренного
центра видна непрерывная вытянутая структура листа, без отдельного звёздного
ядра. Даже прежнее внешнее извлечение `.axy` даёт источник в 1.66 px от этой
позиции: согласие двух детекторов само по себе не удостоверяет звезду.

Это 36-я детекция default, за пределами префикса k=30 выбранной попытки
tetra3. Она включается **позже**, в `match_predictions`, использующий весь
список из 40 детекций. Расстояние до проекции HYG 80761 составляет 7.26
исходного пикселя при допускаемых 7.5 px. После первого fit остаток 7.32 px.
Сопоставление делает яркий элемент переднего плана опорой для уточнения камеры.

## Фиксированный эксперимент

[Подготовка пар](../prototype/eval/robustness_pairs.py) сохраняет неизменные
координаты, ID, внешние извлечения и измерения по апертурам. Редактировать
можно только визуальные метки, выбранную строку `.axy` и пояснения.
[Исполнитель](../prototype/eval/robustness_pair_refit.py) фиксирует входы,
разметку, код и список всех 23 случаев до запуска.

Исследовательский Rust-модуль вызывает существующий
`refine_pose_with_scale`. Поиск соответствий и re-match не выполняются.
Во всех случаях остаются пять свободных параметров и не менее восьми пар.
Для сравнения разных начальных камер вес prior на k1 одинаков: он зафиксирован
по исходной footprint-камере. Аргумент `scale` используется для выравнивания
этого веса; в данной функции он влияет только на prior, координаты не меняет.
Два отдельных контрольных случая сохраняют исходные веса и точно воспроизводят
первые fit итерации 6.

Фиксированный набор испытаний:

1. Два воспроизведения прежнего первого fit.
2. Матрица 2×2: начальная камера control/footprint × пары control (22)/footprint (11).
3. Все 11 вариантов исключения ровно одной footprint-пары, без выбора по остатку.
4. Две начальные камеры для десяти звёздных/смешанных источников без листа;
   две — для девяти источников также без возможного blend.
5. Повторная подгонка десяти пар без листа по центроидам, измеренным непосредственно
   на изображении в апертурах 8 и 12 px, с прежним фоном в кольце 16–22 px.

Измерение геометрии использует неизменные 40 опор итерации 5, в том числе
14 вне обоих прежних входных списков решателя. Состав этих групп не меняется.
Сравнивается **первый fit**, а не финальная камера полного pipeline;
результат 16.65 px нельзя приравнять к новому итоговому решению.

Для одного и того же набора пар изменение начальной камеры даёт максимальное
различие focal менее 6.1e-8 рабочего пикселя, rotation менее 1.5e-11,
k1 менее 2.0e-10. Значения таблицы сохраняются при обеих инициализациях.
Это подтверждает ведущую роль набора соответствий для этих конкретных fit;
не доказывает глобальную единственность минимума оптимизатора.

Удаление листа выводит Albireo обратно внутрь широкого радиуса 25 исходных px
**по прежнему независимому измерению этой звезды**. Но здесь не запускался
следующий re-match: войдёт ли она в новые пары и не вернётся ли лист,
ещё следует проверить. Остальные части поля уже показывают цену изменения.

Измерения по пикселям дают Albireo 16.28–16.69 px при 16.65 px на исходных
детекциях. Направление эффекта не объясняется только выбором центроидов.
Для девяти визуально одиночных источников RMS смещения центроидов остаётся
мал по сравнению с десятками пикселей краевой ошибки; возможный blend
сохраняется отдельной категорией.

## Чувствительность геометрии

Сохранён численный Jacobian той же функции остатков в найденной точке.
Для сравнения обусловленности столбцы data-Jacobian нормированы по норме:
иначе число обусловленности зависело бы от выбора градусов и пикселей
для параметров. Дополнительно рассчитан линейный перенос независимых
возмущений координат опор в проекцию Albireo с действующим prior.

| Набор | Число обусловленности нормированного data-Jacobian | Множитель отклика Albireo | Корреляция откликов focal/k1 |
|---|---:|---:|---:|
| control 22 | 7.47 | 1.01 | −0.862 |
| footprint 11 | 10.16 | 2.77 | −0.956 |
| Без листа, 10 | 11.37 | 3.48 | −0.966 |
| Без листа и blend, 9 | 10.96 | 3.69 | −0.967 |

Множитель — норма линейного оператора переноса, а не калиброванный доверительный
интервал. Значения показывают более слабое ограничение отсутствующего в fit
верхнего левого угла и связь focal/k1. Они **не означают численную сингулярность**.
Удаление физически неверной опоры одновременно уменьшает число геометрических
ограничений: локальная чувствительность растёт, хотя ошибка Albireo уменьшается.
Одна только обусловленность также не удостоверяет правильность соответствий.

## Проверки, ограничения и следующий шаг

23 fit заняли суммарно около 0.57 ms внутри оптимизатора; команда вместе
со сборкой — 47.27 s. Поиск tetra3, получение WCS и повторная детекция
для этих fit не запускались. Rust replay, оба воспроизведения первого fit,
111 Python-тестов, rustfmt и Clippy затронутого crate прошли.

Сохраняются исходные manifest, split/track, фото, опубликованный baseline,
collection-wcs-review, производственные crates и Cargo-зависимости.
Holdout не открывался. Negative и solve rate здесь повторно не измерялись;
производственный алгоритм не менялся. Ручное удаление ложной пары —
диагностический эксперимент, не автоматическое улучшение.

Установлена конкретная связь R01 с refinement: элемент переднего плана
проходит пространственную проверку и влияет на параметры камеры. При этом
остаётся проблема распределения опор по полю; точность всех каталожных
идентичностей и полнота модели камеры не подтверждены. Один development-кадр
не позволяет выбрать универсальный порог, регуляризатор или фильтр.

Следующий ограниченный шаг — replay **полной** цепочки re-match/refinement
с фиксированным кандидатом после диагностического удаления листа. Нужно
проверить возвращение Albireo, возможное повторное включение листа и геометрию
всех прежних опор. Затем сопоставить наблюдение с уже существующими механизмами
отбора источников/неба, прежде чем выбирать автоматическое изменение.

- [Разметка пар](experiments/robustness-iteration-7-review.json): все 11 пар,

- [Результаты](experiments/robustness-iteration-7-geometry.json): все 23 случая,

- [Протокол](experiments/robustness-iteration-7-protocol.json) и
  [проверки](experiments/robustness-iteration-7-checks.json): параметры, хеши и команды.

Нужны сохранённые trace итерации 6, HYG, фото и `.axy`, Python с NumPy,
Astropy и Pillow. Из корня, `REGISTRY` — локальный tetra3 0.8.0:

```bash
python3 prototype/eval/robustness_pairs.py prototype/artifacts/pair-review-new
cp docs/experiments/robustness-iteration-7-review.json prototype/artifacts/pair-review-new/review.json
python3 prototype/eval/robustness_pair_refit.py prepare prototype/artifacts/pair-fit-new --review prototype/artifacts/pair-review-new --registry "$REGISTRY"
python3 prototype/eval/robustness_pair_refit.py run prototype/artifacts/pair-fit-new
python3 prototype/eval/robustness_pair_report.py prototype/artifacts/pair-fit-new --output prototype/artifacts/pair-fit-new/geometry.json
python3 -m unittest discover -s prototype/eval -p 'test_*.py'
```

Использовать новые каталоги для нового прогона. Cargo вызывается из
`prototype/`, с отдельным target и offline. При первом запуске Cargo
сокращает lock-файл изолированного workspace после исключения desktop;
проверки сохраняют хеши до/после и отсутствие новых версий зависимостей.
Основной Cargo.lock не меняется. Времена не обязаны воспроизводиться побайтово.
